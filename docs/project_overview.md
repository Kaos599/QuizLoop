# Project Overview

## Main Goal
The Memorang platform provides an AI‑driven tutoring system that generates interactive simulations for educational content. It enables learners to explore concepts through hands‑on UI interactions without writing code.

## Brief Description
The application combines a Next.js frontend, a LangGraph‑based agent orchestration layer, and a PostgreSQL/Redis backend. Users select a lesson, the agent generates a simulation, and the UI presents a compact, scalable interactive playground.

## Secondary Functionalities
- Lesson goal tracking and automatic completion.
- Scaling/zoom control for compact UI.
- Real‑time AI assistance and feedback.
- PDF upload and content extraction for custom lessons.
